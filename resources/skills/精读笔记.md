# 精读笔记流程

1. 用 library.list（recent: true）或 library.search 找到目标文献的 id，再用 paper.read 分批读全文（pages: [1,2,3,4]、[5,6,7,8]…直到读完；超长论文至少覆盖引言、方法、实验、结论）
2. 按以下骨架整理（每个要点必须标注页码）：
   - 研究问题：作者要解决什么
   - 方法：技术路线/实验设计
   - 核心结论：关键结果与数据
   - 局限性：作者自述的 + 你发现的
   - 对我的启发：可迁移的思路
3. 用 note.append 写入该文献的笔记（标题行：`## 精读笔记（日期）`）
4. 结尾追加「三个追问」：值得问作者/进一步验证的问题
5. 质量门：无页码引用的要点不得超过 1 个；含糊表述（"效果很好"）必须有数据支撑
