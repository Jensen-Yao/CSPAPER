PAPER 04

项目与任务

把阅读、对话和成果组织成研究项目。看板拖拽换列、截止日期、关联文献，今天到期的任务会同时出现在研究台与 Work。

WORK 05

Work 智能体

给一个目标，它先列出可审阅的计划，再检索、读原文、读网页、写笔记、建任务、做对比表；计划执行后按结果续步。权限、技能与逐工具审批都在你手里。

WORK 06

05 / 06
Local first

本地优先

PDF、Markdown 笔记、SQLite 与向量索引都保存在本机。浏览器插件、Word 引文助手和桌面端只通过 127.0.0.1 通信；文件写入带操作日志与备份，崩溃后不会静默重放。

Traceable

可溯源

回答的每个关键论断都绑定到持久化的来源：页码、精确选区、笔记或网页。原文改动后会提示版本差异；题录条目只用于元数据，不会被当成全文结论。

Your model

模型自选

任意 OpenAI 兼容接口，内置智谱、DeepSeek、通义、Kimi、OpenAI、Gemini、Ollama 等预设。思考强度跟随每个模型的能力档案，可在对话里直接新增档位。

FAQ · 常见问题

使用之前，
你可能想问。

我的文献和数据会上传到哪里？

文献、PDF、笔记、会话、向量索引和工具记录都保存在本机，默认放在你选择的文献库文件夹与用户数据目录。只有在发起提问或翻译时，相关的文本片段才会发送给你配置的模型服务；不配置 Key 也能阅读、做笔记和整理文献。

支持哪些模型服务？

任何 OpenAI 兼容接口都可以接入，内置智谱、DeepSeek、通义、Kimi、OpenAI、Gemini、OpenRouter、Ollama、LM Studio 等预设。每个服务商独立保存 Key、Base URL、模型列表与能力档案；嵌入默认可用本地模型，不必上传数据。

能直接从 Zotero 迁移吗？

可以。CSPAPER 能读取 Zotero 的数据目录，把分类、标签、笔记与 PDF 附件迁移进本地文献库；没有 PDF 的条目保留为“题录”，并标注“无原文”，拿到 PDF 后替换文件即可升级为全文。

回答里的引用可信吗？

回答只依据检索到的来源与上下文生成，每个关键论断后紧跟引用角标。点开角标会跳回论文页并高亮精确文本；原文被修改后会提示版本差异，来源不足时模型会明确说明而不是编造。

CSPAPER 免费吗？

CSPAPER 以 Apache-2.0 许可开源，安装包免费。模型调用费用取决于你选择的服务商，本地模型（如 Ollama、LM Studio）不产生费用。
