# 文献日报流程（可配合「自动化」定时执行）

1. 用 library.list 浏览当前库（recent: true 查看最近在读），提炼 3-5 个核心研究关键词
2. 对每个关键词调用 web_search（academic: true）或 research.search_web 检索最新文献，可用年份限定
3. 去重后按与库内主题的相关性排序，取 Top 5-8；信息不足时用 web_fetch 读取摘要页补充
4. 每条输出：标题 / 作者与年份 / 来源 / 一句话相关性理由 / DOI 或 URL
5. 汇总为日报：`# 文献日报（日期）` → `## 今日推荐`（排序条目）→ `## 与库内工作的关联` → `## 建议行动`（值得精读的标 ⭐）
6. 用 standalone_note.save 保存日报；值得跟进的条目可用 task.create 建任务
7. 全程禁止编造条目；检索无结果时如实输出“今日无新增相关文献”
