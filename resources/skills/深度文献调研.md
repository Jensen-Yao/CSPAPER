# 深度文献调研流程

## 第 1 步：多源检索
用 web_search（academic: true）与 research.search_web 以 2-4 组不同关键词检索（同义词、英文中文名各一轮），合并去重。

## 第 2 步：强制验证（防幻觉门）
对每个候选条目：只采信工具返回中**真实出现**的标题/DOI/URL。
- DOI 或 arXiv 链接存在 → 用 paper.import 入库验证
- 无 DOI 但标题可疑 → 放弃，宁缺毋滥
- 禁止编造任何库中不存在的条目

## 第 3 步：筛选（5-8 篇）
筛选标准：与主题相关性、年份（近 3 年优先）、来源质量。逐条给出一句入选理由。

## 第 4 步：阅读与提取
对每篇用 paper.read 阅读前 3-6 页及结论页，提取：研究问题、方法、关键结果（带页码）；发现信息缺口时再补一轮检索。

## 第 5 步：证据式综述
用 synthesis.create 生成综述，或用 standalone_note.save 保存报告，规则：
- 每个结论后标注来源（文献编号与页码）
- 证据不足的槽位写 `<!-- DATA_NEEDED -->`，**禁止编造**
- 结尾列「未覆盖的空白」
