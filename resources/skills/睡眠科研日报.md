# 睡眠科研日报流程（配合「自动化」定时执行）

1. list_library 浏览当前库，提炼 3-5 个核心研究关键词
2. search_papers 分别检索每个关键词（可加 "2025"/"2026" 限定年份）
3. 按与库内主题的相关性排序，取 Top 5-8
4. 对每条输出：标题 / 来源与年份 / 一句话相关性理由 / DOI 或 URL
5. 汇总成日报格式：
   `# 科研日报（日期）` → `## 今日推荐`（排序条目）→ `## 与库内工作的关联` → `## 建议行动`（值得精读的标 ⭐）
6. 用 make_synthesis 不可行时（单日条目少于 2 篇），把日报作为 ai_annotate 写入最相关文献的笔记
7. 全程禁止编造条目；检索无结果时如实输出"今日无新增相关文献"
