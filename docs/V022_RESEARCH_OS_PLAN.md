# CSPAPER 0.22 · Research OS 提质增效计划

版本：v1.0 · 2026-11-27  
目标：把 CSPAPER 从“功能齐全的文献工具”升级为“真正好用、高级、可长期使用的科研操作系统”。

## 1. 产品判断

当前产品已经具备 PDF 精读、可溯源问答、Work Agent、科研日历、阅读专注、对比表、笔记、知识网络、Zotero 迁移等能力，但日常使用仍存在三个结构性问题：

1. **入口分散**：文献、阅读、对话、笔记、日程、任务分布在不同模式，用户打开应用后不知道“下一步做什么”。
2. **研究过程没有闭环**：缺少项目/任务/里程碑的统一组织，阅读、AI 执行、笔记和成果之间靠用户自己记忆。
3. **界面密度与层级不稳定**：功能很多，但主次、留白、字体、状态表达和交互反馈不统一，显得“工具感”强、“产品感”弱。

v0.22 的目标不是继续堆功能，而是把已有能力收束成一条清晰的研究工作流：

```text
今天做什么 → 读什么 → 问什么 → 记什么 → 产出什么 → 下一步是什么
```

## 2. 设计原则

- **任务优先**：首屏先回答“今天要推进什么”，而不是展示功能清单。
- **真实数据**：首页、项目进度、阅读队列、专注统计全部来自当前工作区真实记录。
- **低噪声**：减少装饰性卡片、重复边框、无意义标签；用排版、间距和状态表达层级。
- **键盘优先**：命令面板、快速捕获、阅读队列、对话输入都支持键盘操作。
- **可恢复**：所有新增数据按工作区隔离，写入有校验，删除有确认。
- **可扩展**：项目/任务、研究记录、成果中心共用统一数据契约，为后续版本留接口。

## 3. 信息架构

### 3.1 一级入口

| 入口 | 核心内容 |
|---|---|
| 研究台 | 今日概览、继续阅读、阅读队列、快速捕获、今日日程、最近笔记、最近会话、专注统计 |
| 文献库 | 全部文献 / 最近 / 分类，集合与标签作为可折叠附属区 |
| 阅读器 | PDF 精读、划词、翻译、笔记、阅读专注 |
| 文献问答 | 当前论文 / 选区 / 笔记 / 集合 / Web 来源的可溯源对话 |
| 纵览 | 文献总表、知识网络、统计仪表盘 |
| 笔记 | 全库笔记、划词标注、独立笔记 |
| 对比 | 多文献横向对比表 |
| Work | 今日科研台、项目/任务、科研日历、AI 任务、技能、自动化 |
| 学术检索 | 内置浏览器与站点脚本 |

### 3.2 研究台布局

- 顶部：日期、问候、快速捕获入口、导入/提问/对比/笔记快捷操作。
- 第一行：继续阅读（最近打开的 PDF）、今日专注、文献库健康度。
- 第二行：阅读队列（待读/在读）、今日日程与截止、最近笔记。
- 第三行：最近 Work 会话、最近对比表、快捷入口。
- 空状态必须给出明确下一步，不展示假数据。

### 3.3 Work 布局

- 左侧栏：新建任务、搜索、今日、项目、科研日历、AI 任务、技能、自动化、插件。
- 项目页：项目列表 + 任务看板（待办 / 进行中 / 已完成），支持新增项目、任务、截止日期、关联文献和会话。
- 今日页：今天到期任务、项目进度、阅读队列、日程、专注、最近产物。
- 对话区：统一输入区，支持上下文、技能、模型、思考强度、权限、计划模式、快捷指令。

## 4. 功能范围

### P0 研究台与效率闭环

- 新增 Paper 模式“研究台”入口。
- 首页展示继续阅读、阅读队列、今日日程、最近笔记、最近会话、专注统计、文献库健康度。
- 快速捕获：全局快捷键 `Ctrl/Cmd + Shift + N` 打开快速记录，保存为独立笔记。
- 全局搜索：命令面板同时搜索文献、独立笔记、会话和命令。
- 对话输入区增加快捷指令：总结这篇、找证据、对比方法、生成提纲、追问局限。
- 阅读队列支持“开始阅读 / 标记已读 / 稍后读”。

### P1 项目与任务

- 新增 `research_projects` 和 `research_tasks` 数据表，按工作区隔离。
- 项目字段：名称、描述、颜色、状态、截止日期、创建/更新时间。
- 任务字段：标题、备注、状态、优先级、截止日期、关联文献、关联会话、完成时间。
- 项目页支持新增/编辑/删除项目，新增/编辑/删除/完成任务。
- 今日页汇总今天到期和逾期任务。
- 任务可从日程“交给 Work”生成 AI 任务草稿。

### P2 对话与阅读体验

- 对话输入区增加快捷指令和上下文摘要。
- 阅读队列与阅读状态联动。
- 最近笔记/会话可从研究台直接打开。
- 命令面板支持笔记和会话搜索结果。

### P3 视觉系统升级

- 统一字体、字号、圆角、阴影、间距和状态色。
- 重做研究台、项目页、对话输入区、文献库卡片、顶部导航和状态栏。
- 深浅主题、窄窗、键盘焦点、减少动画全部覆盖。
- 不改变既有品牌资产，不引入未授权依赖。

### P4 发布面重做

- 新 README：品牌横幅、产品定位、核心能力、界面截图、快速开始、架构、验证、路线图。
- 新 GitHub Pages 首页：产品优先的 hero、功能分区、工作流、界面 gallery、下载、FAQ。
- 新在线演示：研究台 / 阅读器 / Work / 对比 / 笔记多视图可切换。
- 新社交分享横幅：`docs/assets/og-banner.png`。
- 所有旧演示链接替换为新演示链接，旧 `demo.html` 做重定向兼容。

## 5. 数据与接口

### 5.1 新增迁移

`011-research-projects.ts`：

- `research_projects`
- `research_tasks`
- 索引：workspace + updated_at、workspace + status、project + status。

### 5.2 新增 IPC

- `projects:list`
- `projects:save`
- `projects:remove`
- `tasks:list`
- `tasks:save`
- `tasks:remove`

所有接口按当前工作区隔离；删除项目级联删除任务；任务关联文献/会话时校验归属。

### 5.3 类型契约

在 `src/shared/projects.ts` 定义 Zod schema 和 TypeScript 类型，主进程与渲染端共用。

## 7. UIYC 参考与设计决策

- [Nuxt Dashboard](https://uizze.com/apps/d07add01-d679-42de-9813-15dee57c0c89)：数据密集型工作台采用清晰表格、紧凑筛选和低噪声侧栏；CSPAPER 研究台采用同样的“任务优先、数据靠后”层级。
- [OpenPanel](https://uizze.com/apps/119a7693-1b14-4b0f-a983-353759457488)：分析页用留白和分组建立层级，而不是堆卡片；CSPAPER 首页采用“主列 + 侧栏”结构。
- [Normal Tools](https://uizze.com/apps/1f8c13f2-7ef2-42e8-97af-aee67bf3d0b1)：工具型产品首页用编辑感排版和明确入口；CSPAPER 官网采用产品优先、少装饰、强内容的表达。
- [Arcade](https://uizze.com/apps/f13486c6-1dba-4d11-98a7-1a35dc42b598)：产品演示用真实界面和清晰段落讲故事；CSPAPER 新 demo 采用可切换的真实界面模拟。

设计合同：

- 目的：让研究者在一屏内知道“读什么、问什么、记什么、推进什么”。
- 构图：研究台采用 12 栏网格，主列 8 栏、侧栏 4 栏；窄窗折叠为单列。
- 字体：界面使用系统中文无衬线；官网使用 Inter + Noto Sans SC，标题紧凑，正文舒适。
- 色彩：保留 CSPAPER 朱砂红作为唯一强调色；中性色承担层级；语义色只用于状态。
- 状态：加载、空、错误、成功、禁用、选中、展开、恢复全部覆盖。
- 完成条件：真实 Electron 界面在 1500×940、1100×760、窄窗下可完成核心任务；无 renderer 异常；README/Pages/demo 无 404。

## 10. 非目标

- 多人协作、跨设备同步、完整实验计算平台不在本版范围。
- 不改变现有文献库目录结构、PDF 阅读器核心渲染、Zotero 迁移逻辑。
- 不引入未授权字体、图片或付费服务。
