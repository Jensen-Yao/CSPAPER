# 引用格式审计流程

1. 定位待审计文本（用户提供或 read_paper 读取）
2. 提取全部引用点（页码标注 / DOI / 作者-年份）
3. 对每条引用：
   - list_library / search_library 验证文献真实存在于库
   - cite_format 用目标样式重排，比对格式一致性
4. 输出审计报告：
   - ✅ 通过条目数
   - ⚠️ 格式不一致清单（附修正建议）
   - ❌ 疑似虚构/库中不存在的引用清单（最高优先级修正）
5. 质量门：任何 ❌ 项未处理前，审计不通过
