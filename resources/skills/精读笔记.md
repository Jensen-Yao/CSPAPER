# 精读笔记流程

1. read_paper 读全文（分批：1-4、5-8…直到读完）
2. 按以下骨架整理（每个要点必须标注页码）：
   - 研究问题：作者要解决什么
   - 方法：技术路线/实验设计
   - 核心结论：关键结果与数据
   - 局限性：作者自述的 + 你发现的
   - 对我的启发：可迁移的思路
3. 用 write_note 写入我的笔记（标题行：`## 精读笔记（日期）`）
4. 结尾追加「三个追问」：值得问作者/进一步验证的问题
5. 质量门：无页码引用的要点不得超过 1 个；含糊表述（"效果很好"）必须有数据支撑
