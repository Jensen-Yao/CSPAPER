# Word / WPS 插引文

把 CSPAPER 文献库里的文献以 **GB/T 7714-2015**（中文论文国标）格式插入 Word / WPS 文档。两种用法：

## 方式一：Word 加载项（任务窗格，推荐）

> 前提：CSPAPER 桌面端正在运行（本地服务端口 `24517`）。

1. 打开 Word → **插入** → **获取加载项**（或「我的加载项」）→ 右上角「**上传我的加载项**」
2. 选择本目录的 [`manifest.xml`](./manifest.xml)
3. 右侧出现「CSPAPER 引文」任务窗格：搜索 → 勾选 → 「在光标处插入引用 [n]」或「文末插入参考文献列表」

> 桌面版 Word 若提示无法加载：确认 CSPAPER 正在运行；或用方式二（任何版本都能用）。

## 方式二：引文助手网页（Word / WPS 通用，零安装）

1. 浏览器打开 **<http://127.0.0.1:24517/cite-ui>**（CSPAPER 运行时可用）
2. 搜索文献 → 勾选 → 「生成参考文献列表」→ 「复制」
3. 粘贴到 Word / WPS / LaTeX 任何编辑器里

## 工作原理

插件不访问任何远程服务器：搜索与引文生成都调用 CSPAPER 桌面端的本地服务（`127.0.0.1:24517`）：

- `GET /papers?q=` 检索文献库
- `GET /cite?ids=1,2&style=gbt7714|bibtex` 生成引文（也支持 BibTeX）

## WPS 补充

WPS 暂不支持 Office 加载项，请用**方式二**。也支持直接粘贴 BibTeX（`/cite?style=bibtex`）供 LaTeX 用户使用。
